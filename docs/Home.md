# SiteScout vault

This `docs/` folder is the team's **Obsidian vault**. Open Obsidian, choose *Open folder as vault*, and pick `docs/`. Notes sync through git like any other file.

## Index

- [[api-contract]] — the shared JSON contract. Read first.
- [[Tasks]] — who owns what, and branch names.
- [[Workflow]] — git rules for the day.
- [[Decisions]] — running log of decisions.
- [[Pitch]] — 3-minute pitch notes and demo script.

## Vault rules

- Only commit notes, not personal Obsidian state (`.obsidian/workspace*.json` is git-ignored).
- Use `[[wikilinks]]` between notes.
- Don't put secrets (API keys) in any note.
