# Pitch

Back to [[Home]].

**One line:** before you sign a lease, see the evidence for where to sign it.

Format: 3-minute pitch + 2-minute Q&A. Lead with the live demo. Problem, live demo, impact.

## Demo path
1. Specialty café, tight budget, students + office workers.
2. Map shades every Cork cell; five numbered pins.
3. Agent panel: 4 specialists, challenger, reporter.
4. Pick #1: evidence vs Cork median, named competitors, risks.
5. Comparison table; switch budget to flexible; ranking moves.
6. Close on the limits: cost is a proxy, OSM counts can be incomplete.
